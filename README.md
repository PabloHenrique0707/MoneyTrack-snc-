## 📌 Sobre o Projeto

O **MoneyTrack** é uma aplicação web completa desenvolvida para o controle e gerenciamento de finanças pessoais. Ele resolve o problema da falta de organização financeira trazendo uma interface centralizada, moderna (Dark Mode Premium) e responsiva. 

Com o MoneyTrack, o usuário pode acompanhar lançamentos de receitas e despesas em tempo real, monitorar o progresso de metas de economia e visualizar a distribuição dos seus gastos por meio de gráficos interativos.

---

## ✨ Funcionalidades Principais

* 🔐 **Autenticação de Usuário:** Login e cadastro seguro de usuários.
* 💵 **Gestão de Saldo e Totais:** Cálculo automático de saldo atual, receitas e despesas acumuladas.
* 📝 **Lançamento de Transações:** Cadastro de movimentações com descrição, valor, categoria e tipo (receita/despesa).
* 🔍 **Histórico e Filtros:** Visualização detalhada de lançamentos com filtros avançados.
* 🎯 **Controle de Metas Financeiras:** Criação, edição, progresso visual e exclusão de metas.
* 📊 **Gráficos Interativos:** Gráfico dinâmico em rosca integrado via **Chart.js**.
* 👤 **Gestão de Perfil:** Edição de dados cadastrais, troca de foto de perfil e exclusão de conta.
* 📱 **Layout Totalmente Responsivo:** Experiência otimizada para desktops, tablets e smartphones.
